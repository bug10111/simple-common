# simple-common

#### 介绍
简单分享一些拧螺丝的经验，会持续更新，目标是让大多数人可以直接使用这个框架，即便不直接使用，也能将项目的核心包拿出去单独打包引入，提高开发效率。所以框架会先从公共的工具、包、组件开始，慢慢集成为框架。框架可以单体运行，也可快速拆解成微服务，尽量让更多的小伙伴都能直接使用，并且过度公司不同发展阶段。目前设计已完成，外部框架包括但不限于：spring boot3.+、mybatis plus、knife4j、hutool、redisson、xxl-job、minio、rabbimq、rocketmq、spring cloud alibaba等。
